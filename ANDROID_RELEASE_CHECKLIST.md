## AAB and APK artifacts

An Android App Bundle (`.aab`) is the artifact intended for Google Play submission. An APK (`.apk`) is generally used for direct installation and device testing. Do not assume that an APK generated by a Publish or preview flow can be uploaded as the production artifact for a new Google Play app.

After using Manus Publish, inspect the resulting build/publish card in the Manus Management UI and download the listed Android artifact. If the result lists only an APK, use it for device testing and create a production AAB through the supported EAS/Android release build path. For an EAS build, the build details page and the command output provide the download link; the EAS dashboard also lists completed builds. A local EAS submission can use `eas submit --platform android --path ./your-app.aab` after the AAB is downloaded.

A standard EAS production flow is:

```bash
npm install --global eas-cli
eas login
eas build --platform android --profile production
eas submit --platform android --latest
```

The final submission requires a Google Play Developer account, an app created in Play Console, a unique package name, Android signing credentials, and—when using automated EAS submission—a Google Service Account key configured in EAS. Store listing metadata, screenshots, content declarations, Data Safety, app access instructions, and testing tracks are completed in Play Console rather than by uploading the binary alone.

## Checkpoint semantics

A URI such as `manus-webdev://a5e652e2` identifies an internal Manus project checkpoint. It is a versioned snapshot used to review, restore, or continue the project. It is not an Android package, an APK, an AAB, a Play Console application, or a Google Play release.

The checkpoint identifier is generated by Manus and cannot be changed manually to `lyvietkhang-webdev`. The user-facing app name, Android package identifier, and project slug are separate fields. The app identity has already been changed to `Mathematics 4.0` and `com.vietkhang.math40edu`, while the Manus checkpoint URI remains platform-generated.
